# Tove Sign

Static site for Tove Sign. No build step. Hosted on GitHub Pages, DNS through Cloudflare.

## Before launch
1. Get a free access key at web3forms.com using yong@tovesign.com and replace `REPLACE_WITH_WEB3FORMS_ACCESS_KEY` in every HTML file.
2. Add real project photos (see /images, when added).

## Deploy
Repo Settings > Pages > Deploy from branch > `main` / root. Custom domain: tovesign.com. Enforce HTTPS.
